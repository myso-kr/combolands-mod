# Combolands — mod

Korean language patch, cheat widget, and autoplay for the Steam roguelike citybuilder
*Combolands: Roguelike Citybuilder* (Crux Games, AppID 4075620).

> **Status: the language patch works.** Every string the game has is translated and
> renders in the retail build. The cheat widget and autoplay are not written yet.
> No game file is modified — the loader and the mod are added beside them and
> uninstall by deletion.

## How it works

The game already had a localisation scaffold — every translatable string is a
`LocalizedStringAsset` with a `Key` — so the whole translation is one Harmony
postfix on `GetText()`, joined on the key rather than on the English. Crux can
reword their own text without moving ours.

None of the game's five TextMeshPro fonts has a single Hangul glyph, so the mod
builds a **Galmuri11** font asset from a TTF at runtime, fills its atlas on demand,
and hangs it off every font as a fallback — re-registering on each scene load,
because two of those fonts only appear with the game scene.

## Configuration

`UserData/MelonPreferences.cfg`, written on first run:

| Key | Default | |
|---|---|---|
| `Language` | `ko` | folder under `UserData/Combolands/locale`. Empty turns translation off |
| `Translate` | `true` | |
| `FontScale` | `0.8` | Korean glyph size against the game's own font. Hangul fills its em box and Latin does not, so 1.0 towers |
| `FontSamplingPointSize` | `32` | atlas resolution, not rendered size |
| `FontFile` | `Galmuri11.ttf` | under `UserData/Combolands/fonts` |
| `DumpStrings` | `false` | developer: write the English out to `generated/` |

## Building

```
dotnet build src/Combolands.Mod -c Release
python tools/lint-locale.py locale/ko/strings.json --english generated/strings.en.json
python tools/status.py
```

`GameDir` defaults to the Steam path and is overridable:
`-p:GameDir="D:\SteamLibrary\steamapps\common\Combolands"`.
